지금 응급실 상태

꽉 참 (남은 병상 0 이하) 1~2개 남음 3개 이상 입력 60분 넘게 지남

점을 누르면 남은 병상, 지금까지 꽉 찼던 비율, 수용 불가 질환을 볼 수 있어요.

시간대별 꽉 찬 비율

최근 7일 꽉 찬 응급실 수

수집할 때마다 남은 병상이 0 이하인 응급실이 몇 곳이었는지 보여줘요.

거절 확률은 이렇게 계산해요

통계표를 불러오는 중…

  1. ① 10분마다 기록응급실마다 남은 병상(hvec)을 저장해요. 0 이하이면 '거절(수용 곤란) 상태'로 봐요.
  2. ② 짝짓기같은 병원의 "지금 남은 병상"과 "10·20·30·40·50·60분 뒤 남은 병상"(±3분)을 한 쌍으로 묶어요. 병원 입력이 60분 넘게 지난 기록은 '지금 상태'로 쓰지 않아요.
  3. ③ 칸별로 세기지금 병상 구간 6개 × 도착까지 시간 6개 × 시간대 6개 = 216칸. 칸마다 "뒤 기록이 0 이하였던 횟수 k ÷ 전체 횟수 n"을 세요.
  4. ④ 기록이 적은 칸 보정p = (k + 30 × 기준값) ÷ (n + 30). 전체 병원 → 같은 시간대 → 이 병원 순으로 적용해요. 사이 시간(예: 14분)은 10분과 20분 값을 직선으로 이어요.기록이 많을수록 그 병원 자신의 비율에 가까워져요.

결과: 지금 남은 병상이 k개일 때, n분 뒤 병상이 0 이하였던 비율

칸의 큰 숫자는 비율, 작은 숫자는 k/n(0 이하였던 횟수 / 전체 횟수)이에요. 경기도 응급실 전체를 합친 값이고, '–'는 아직 기록이 없는 칸이에요.

병원 하나로 계산 따라가기

병원별 결과: 지금 상태에서 20분 뒤 도착하면

줄을 누르면 위에서 그 병원의 계산 과정을 볼 수 있어요. '병원 기록 비중'은 마지막 보정에서 이 병원 자신의 기록이 차지한 몫(n ÷ (n + 30))이에요. 기록이 쌓일수록 커져요.
