① 계산 방법

"지금 남은 병상이 몇 개인 응급실에 몇 분 뒤 도착하면 꽉 차 있을까"를, 지금까지 실제로 일어난 일을 세어서 계산해요.

  1. 1. 10분마다 기록응급실마다 남은 병상(hvec)을 저장해요. 0 이하이면 '거절(수용 곤란) 상태'로 봐요.
  2. 2. 짝짓기같은 병원의 "지금 남은 병상"과 "10·20·30·40·50·60분 뒤 남은 병상"(±3분)을 한 쌍으로 묶어요. 병원 입력이 60분 넘게 지난 기록은 '지금 상태'로 쓰지 않아요.
  3. 3. 칸별로 세기지금 병상 구간 6개 × 도착까지 시간 6개 × 시간대 6개 = 216칸. 칸마다 k ÷ n을 세요. (k: 그 칸에서 도착 시점에 0 이하였던 횟수, n: 그 칸의 전체 짝 수)
  4. 4. 기록이 적은 칸 보정기록이 적은 칸은 비율을 그대로 믿지 않고, 비슷한 병원(같은 등급)의 비율 쪽으로 당겨서 써요. 사이 시간(예: 14분)은 10분과 20분 값을 직선으로 이어요.아래 '기준값'과 '등급'에서 자세히 설명해요.

기록이 적은 칸은 어떻게 하나요 — 기준값

한 칸은 이 병원 × 지금 남은 병상 구간 × 도착까지 시간 × 시간대가 모두 같은 경우만 모아요. 아직 기록이 짧아 병원 하나의 기록이 216칸으로 잘게 나뉘면, 칸마다 짝이 몇 개밖에 안 남아요.

예를 들어 짝이 3개인데 꽉 찬 적이 0번이면, 그대로 쓸 경우 거절 확률이 0%가 돼요. 세 번 봤을 뿐인데 "절대 안 막힌다"고 말하는 셈이죠. 반대로 1개 중 1번이면 100%가 돼요. 기록이 적을수록 우연에 크게 흔들려요. 그래서 기준값 쪽으로 당겨서 써요.

p = (k + 30 × q) ÷ (n + 30)
(p: 이 병원의 거절 확률 · k: 이 병원 그 칸에서 0 이하였던 횟수 · n: 이 병원 그 칸의 짝 수 · q: 기준값(같은 등급 병원들의 비율) · 30: 기준값을 '가상의 짝 30개'만큼 믿는다는 뜻)

짝이 많을수록 병원 자신의 비율을 더 믿어요. 병원 자신의 비중은 n ÷ (n + 30)이에요 (n: 그 칸의 짝 수).

기준값 q는 같은 등급 병원들의 기록 중 지금 병상 구간과 도착까지 시간이 같은 것을 시간대 구분 없이 모두 합쳐서 구해요. 합치면 기록이 많아져서 기준으로 쓰기에 안정적이에요.

q = (K + 0.5) ÷ (N + 1)
(q: 기준값 · K: 같은 등급 병원들에서 지금 병상 구간·도착까지 시간이 같은 짝 중 도착 시점에 0 이하였던 횟수를 모두 더한 값(시간대 합침) · N: 그런 짝의 수를 모두 더한 값 · 0.5와 1: 기록이 적어도 0%나 100%로 딱 떨어지지 않게 더하는 수)

비슷한 병원 = 같은 등급

병원마다 지금까지 모든 수집 기록 중 남은 병상이 0 이하였던 비율(꽉 찬 비율)을 계산해서 세 등급으로 나눠요.

  • 기록이 36번(약 6시간분)보다 적은 병원은 등급을 매기지 않고, 예전 방식(전체 병원 → 같은 시간대 → 이 병원)으로 계산해요.
  • 등급은 수집할 때마다 다시 매겨요. A 병원이 한 번이라도 꽉 차면 다음 계산부터 B로 옮겨가요.
  • 꽉 찬 비율로 나누는 이유: 맞히려는 것이 "도착했을 때 꽉 차 있을까"라서, 평소에 얼마나 자주 꽉 차는지가 결과와 가장 직접 이어져요. 같은 "1개 남음"이라도 평소 꽉 찬 적 없는 병원은 다시 여유가 생기는 경우가 많고, 늘 꽉 차는 병원은 곧 0이 되는 경우가 많아요. 그래서 둘의 기록을 섞지 않아요.
  • 경계를 0%와 50%로 정한 이유: 0%는 "한 번도 꽉 찬 적 없는 병원"과 "가끔이라도 꽉 차는 병원"을 가르는 가장 분명한 선이에요. 50%는 "대부분의 시간 꽉 차 있는 병원"을 따로 떼어 다른 병원 계산에 섞이지 않게 하려는 선이에요. 50% 대신 30%나 70%로 바꿔 시험해도 정확도가 거의 같았고, A와 나머지 두 등급으로만 나누면 정확도가 떨어졌어요.
  • 지금은 보지 않는 것: 병원 규모(응급실 기준 병상 수), 종류(권역·지역센터 등), 위치, 하루 중 붐비는 시간대. 기록이 더 쌓이면 하나씩 넣어 보고 ⑤ 정확도 점검으로 실제로 나아지는지 확인할 다음 후보예요.

왜 이렇게 바꿨나요 (2026-10-26)

  • 예전에는 기준값을 전체 병원 합계에서 가져왔어요. 그런데 "지금 꽉 참" 기록의 약 39%가 늘 꽉 차 있는 분당서울대 한 곳에서 나와서, 거의 꽉 차지 않는 병원의 확률까지 끌어올렸어요(남은 병상 1개일 때 예측 52%, 실제 24%).
  • 같은 등급끼리만 묶자 같은 기록으로 시점을 바꿔 4번 검증했을 때 Brier 점수가 약 9%, 보정 오차가 약 38% 줄었어요 (Brier 점수: (예측 확률 − 실제 결과)²의 평균, 실제 결과는 꽉 찼으면 1·아니면 0 · 보정 오차: 예측 확률과 실제로 일어난 비율의 차이).
  • 예 (10-26 20:40 기준, 20분 뒤 거절 확률): 현대병원(A등급, 1개 남음) 29.0% → 4.2%, 참조은병원(B등급, 0개) 79.3% → 70.7%, 분당서울대(C등급) 88.1% → 99.8%.
  • 통계를 내는 개념은 그대로예요. "같은 조건에서 실제로 일어난 비율을 센다"는 점은 같고, 기록이 부족할 때 누구를 참고하느냐만 바뀌었어요.

기록이 쌓이면 기준값과 등급은 필요 없어지나요?

  • 흔한 상황에서는 저절로 작아져요: 위 표처럼 짝이 수백 개가 되면 병원 자신의 비율이 90% 넘게 반영돼요. 따로 끌 필요 없이 공식이 알아서 넘어가요.
  • 드문 상황에서는 계속 필요해요: 꽉 찬 적 없는 병원이 "남은 병상 1개"가 되는 일은 몇 달이 지나도 몇 번 안 될 수 있어요. 그런데 그런 순간의 확률이 가장 중요해요.
  • 나중에 더 잘게 나누면 칸이 다시 비어요: 요일별, 정원 대비 비율 구간 등으로 나누면 칸 하나의 기록이 다시 줄어요. 새로 수집되는 병원이나 계절 변화(독감 유행 등)가 있을 때도 처음에는 기준값에 기대야 해요.
  • 등급 나누기 자체는 기록이 많이 쌓이면 더 정교한 방법(예: 꽉 찬 비율이 비슷할수록 더 많이 참고)으로 바뀔 수 있어요.

왜 이렇게 계산하나요 (근거)

  • 조건부 상대도수 k ÷ n: 같은 조건(지금 병상 구간·도착까지 시간·시간대)에서 실제로 일어난 비율을 확률로 써요. 기록이 쌓일수록 실제 확률에 가까워져요(큰 수의 법칙). (k: 그 조건에서 0 이하였던 횟수, n: 그 조건의 전체 짝 수)
  • (K + 0.5) ÷ (N + 1): 베이즈 추정값(제프리스 사전분포)이에요. 기록이 적을 때 0%나 100%로 딱 떨어지는 것을 막아요. (K: 0 이하였던 횟수 합, N: 짝 수 합)
  • (k + 30 × q) ÷ (n + 30): 베타-이항 모형의 '수축' 추정(경험적 베이즈)이에요. 짝 수 n이 30보다 훨씬 많으면 병원 자신의 비율, 적으면 기준값 q에 가까워져요. (k: 0 이하였던 횟수, n: 짝 수, q: 기준값)
  • 직선 보간: 10분 간격 사이 도착 시간은 양옆 값을 시간 비율대로 섞어요. 예: 14분 = 10분 값 × 0.6 + 20분 값 × 0.4.

알고 써야 할 한계

  • 거절 상태 = 남은 병상 0 이하로만 정했어요. 전문의 부재 같은 다른 거절 사유는 들어 있지 않아요.
  • 병원이 직접 입력한 값이라, 입력이 늦거나 틀리면 계산도 그만큼 틀려요(입력이 자주 늦는 병원은 '수집 상태' 탭에서 볼 수 있어요).
  • 병원 수가 적은 등급(특히 C등급, 위 표)은 기준값이 몇 병원의 기록에 크게 좌우돼요. 등급은 수집할 때마다 다시 매기기 때문에 경계(0%, 50%) 근처 병원은 등급이 바뀔 수 있어요. 입력이 자주 늦는 병원은 꽉 찬 비율이 정확하지 않을 수 있어요. 1주일 기록으로 다시 확인할 예정이에요.

② 결과표: 지금 남은 병상별로, 몇 분 뒤 0 이하였던 비율

경기도 응급실 전체를 합친 실제 비율(보정 전 k/n)이에요. 시간대를 골라 볼 수 있어요.

칸의 큰 숫자는 비율, 작은 숫자는 k/n(0 이하였던 횟수 / 전체 횟수)이에요. 0%는 '지금까지 한 번도 없었다'는 뜻이지 '절대 없다'는 뜻이 아니에요. 칸에 마우스를 올리면 95% 신뢰 상한(대략 3 ÷ n, n: 그 칸의 전체 짝 수)을 보여 줘요. 이 표는 보정 전 값이라 기준값·등급이 들어가지 않아요.

③ 병원 하나로 계산 따라가기

고른 병원의 지금 상태에서 도착 시간별 거절 확률이 어떻게 나오는지 단계마다 보여 줘요.

④ 병원별 결과: 지금 상태에서 20분 뒤 도착하면

모든 응급실의 20분 뒤 거절 확률이에요. 줄을 누르면 ③에서 계산 과정을 볼 수 있어요.

'0.1% 미만'은 그 병상 구간에서 지금까지 거의(또는 한 번도) 꽉 찬 적이 없는 병원이에요. 확률이 정확히 0이라는 뜻은 아니에요. '병원 기록 비중'은 마지막 보정에서 이 병원 자신의 기록이 차지한 몫 n ÷ (n + 30)이에요 (n: 이 병원 그 칸의 짝 수).

⑤ 정확도 점검

앞부분 기간의 기록만으로 통계표를 만들고, 뒷부분 기간에 실제로 어땠는지 맞혀 봐요(미래를 미리 보지 않도록 시간 순서로 나눔).

수집률

10분 칸 수집률 = 기간 안의 10분 칸 중 가용병상 기록이 있는 칸의 비율이에요. 기능별 숫자는 실행 기록(성공·실패·건너뜀) 수예요.

실패 기록을 원인별로 묶어 본 결과예요.

수집 간격

가용병상 기록 사이 간격이에요(최근 7일). 정상은 약 10분이에요.

수집에서 빠진 기관

경기도 응급의료기관 목록에는 있지만 실시간 병상 정보를 내지 않아 수집·계산에서 빠진 곳이에요.

응급실별 입력 신선도

병원이 값을 얼마나 제때 입력하는지예요. '60분 넘은 비율'이 높을수록 그 병원 기록은 '지금 상태'로 덜 쓰여요.

기호 풀이

이 현황판의 식에 나오는 문자와 숫자가 뜻하는 것이에요.

기호뜻
p거절 확률: 그 병원에 도착했을 때 남은 병상이 0 이하일 확률
k그 칸(같은 병원·같은 지금 병상 구간·같은 도착까지 시간·같은 시간대)에서 도착 시점에 남은 병상이 0 이하였던 횟수
n그 칸의 전체 짝 수 ('지금 기록'과 '몇 분 뒤 기록'을 한 쌍으로 묶은 것의 개수)
K, N합계 칸의 k와 n: 같은 등급 병원들에서 지금 병상 구간·도착까지 시간이 같은 짝을 시간대 구분 없이 모두 더한 '0 이하였던 횟수'(K)와 '짝 수'(N). 등급이 없는 병원은 전체 병원 합계
q기준값: 같은 등급 병원들의 비율 (K + 0.5) ÷ (N + 1)
30기준값을 '가상의 짝 30개'만큼 믿는다는 뜻의 수 (기록이 30개보다 많으면 병원 자신의 비율이 더 크게 반영됨)
n ÷ (n + 30)병원 기록 비중: 마지막 확률에서 병원 자신의 기록이 차지하는 몫
0.5, 1(K + 0.5) ÷ (N + 1)에서 기록이 적어도 0%나 100%로 딱 떨어지지 않게 더하는 수
3 ÷ n한 번도 일어나지 않았을 때(k = 0) 실제 확률의 95% 신뢰 상한 (3의 법칙)
hvec공공데이터의 응급실 일반병상 가용 수(남은 병상). 0 이하이면 꽉 참
±3분짝짓기 허용 오차: '20분 뒤 기록'은 17~23분 뒤 기록 중 가장 가까운 것
Brier 점수(예측 확률 − 실제 결과)²의 평균. 실제 결과는 꽉 찼으면 1, 아니면 0. 0에 가까울수록 정확
%p퍼센트포인트: 두 퍼센트 값의 차이 (예: 25%와 20%의 차이 = 5%p)
출처: 공공데이터포털 「국립중앙의료원_전국 응급의료기관 정보 조회 서비스」. 꽉 참 = 응급실 일반병상 가용 수(hvec) 0 이하. 병상 정보는 병원이 입력하는 값이라 실제와 다를 수 있어요.
