      계산 방법과 한계

      실효 도착 시간 = 도로 이동 시간 + 도착 시점 거절 확률 × (확인 지연 3분 + 다음 응급실까지의 실효 도착 시간). 거절이 이어지는 경우를 3단계까지 계산해요.

      거절 확률은 수집한 공공데이터에서 "남은 병상이 k개였을 때 n분 뒤 병상이 0 이하였던 비율"을 시간대·병원별로 센 값이에요.

      출발지 → 응급실 시간은 카카오 실시간 길찾기, 응급실 → 응급실 시간은 하루 4번 계산해 둔 표를 써요. 표에 없는 짝은 직선 거리로 추정해요.

      전문의 부재처럼 공공데이터에 없는 거절 사유는 반영하지 않아요. 병상 정보는 병원이 입력한 값이라 실제와 다를 수 있어요. 병원끼리의 거절은 서로 독립이라고 가정해요. 경기도 응급실만 계산해요.
